# PromptedSite - Luxury Kinetic Web Experience (Agrumea Edition)

Production-grade mirrored & rebranded Nuxt 3 web experience with 3D canvas jar label projection, smooth parallax scrolling, and responsive full-page navigation.

## Features
- **3D Canvas Jar Label Projection**: Offscreen Three.js WebGL rendering projected seamlessly onto 2D canvas wraps.
- **Kinetic Parallax Carousel**: Interactive curved slider trajectory with touch, drag, and mousewheel support.
- **Complete Rebranding**: Photorealistic custom labels, elegant serif typography (`PROMPTEDSITE Atelier`), and rebranded CMS metadata.
- **Zero External Dependencies**: All SSR routes, Nuxt bundles, CSS, fonts, and WebP product images are self-hosted locally.

## Running Locally

```bash
python server.py 8085
```

Open your browser at:
```
http://localhost:8085/en/
```
